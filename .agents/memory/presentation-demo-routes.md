---
name: Presentation demo routes
description: Which mobile routes are reliable sources for screenshots used in the Kopi Garut presentation.
---

Public-facing mobile routes are reliable screenshot sources for the presentation. Role-specific dashboard routes can redirect to the role-selection/login screen when opened directly, so they are not suitable as deck visuals unless the role has already been selected in the session.

**Why:** Direct screenshot capture of role-gated routes produced identical login screens instead of the intended dashboard content.

**How to apply:** Prefer public routes such as the home, catalog, regions, program, partnership, events, tourism, diversification, and traceability screens when collecting presentation imagery. Use a role-specific route only after verifying the session is in the intended role.
