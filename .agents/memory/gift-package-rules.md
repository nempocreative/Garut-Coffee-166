---
name: Gift package customization rules
description: Minimum order and pricing requirements for box and text customization.
---

Custom box orders require at least 12 packages and add Rp25,000 per package. Custom writing alone has no minimum order. The standard Garut Beans box is included in the package price.

**Why:** the user specified these pricing and minimum-order rules for Garut Beans souvenir packages.

**How to apply:** Keep the rules consistent in the package builder, cart quantity validation, and order totals.
